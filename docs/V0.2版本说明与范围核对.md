# V0.2 版本说明与范围核对（网页核心版）

## 1. 版本定位

V0.2 网页核心版是在 V0.1 初始代码基础上的功能补强版本。继续使用原生 HTML、CSS、JavaScript 和 localStorage，不新增后端、数据库或前端框架。

本版本只交付自习室预约网页产品。项目管理实验中规划的 PM Agent、Architect Agent、Planner Agent、Developer Agent、QA Agent 和 Change Control Agent，是项目过程中的管理与开发职能角色，应在实验报告、角色提示词、交互记录和管理过程证据中体现，不嵌入最终学生预约网页。学生是网页使用者及外部用户干系人，不单独设置 Student Agent。因此，本网页核心版不包含任何 Agent 网页模拟台、脚本或 API 调用。

## 2. 对照范围说明书 S-01 至 S-08

| 范围编号 | 范围要求 | V0.2 网页核心版状态 | 后续核验方式 |
|---|---|---|---|
| S-01 | 展示预设自习室信息 | 两间预设自习室，显示名称、楼层和座位数量 | 浏览器检查 |
| S-02 | 展示座位布局及空闲/已预约/选中状态 | 座位网格根据所选日期、时间和预约数据更新状态 | 切换房间、日期和时段检查 |
| S-03 | 选择日期与时间段，无效选择提示 | 日期限制为今天至未来7天；整点时段08:00—22:00；非法时段提示 | 边界日期和时间测试 |
| S-04 | 创建预约 | 演示登录后选择空闲座位并创建预约记录 | 浏览器实际预约 |
| S-05 | 冲突检查 | 同一房间、座位、日期的重叠时段禁止重复预约；相邻时段允许 | 冲突与相邻时段测试 |
| S-06 | 我的预约 | 仅显示当前演示用户的预约记录 | 切换演示身份检查 |
| S-07 | 取消预约 | 未结束预约可取消；取消记录保留且释放时段 | 取消前后对比 |
| S-08 | localStorage 本地持久化；不可用时提示或降级 | 保留 V0.1 数据键；增加存储可用性检查、读取损坏保护和保存失败提示 | 刷新测试、禁用存储测试 |

> 说明：当前正式范围说明书 V1.2 将产品功能编号确定为 S-01 至 S-08；学生是预约网页的使用者及外部用户干系人，不单独设置 Student Agent。六类项目管理 Agent 只在项目管理实验过程中开展角色化协作。

## 3. V0.2 相比 V0.1 的主要改进

1. 加强 localStorage 可用性检查、损坏数据保护和保存失败提示。
2. 保留 V0.1 的存储键名，避免升级后丢失原有演示数据。
3. 本版本不包含网页内的 Agent 模拟页面、脚本或测试模块，使预约网页产品与项目管理实验角色保持边界清晰。
4. 在导航中仅保留首页、预约座位和我的预约三个产品页面。

## 4. 明确未纳入的功能

- CR-001：直接修改既有预约时间。当前仍待小组正式评审，不属于 V0.2 已实现功能。
- 真实校园身份认证、云端数据库、跨设备同步和生产级并发控制。
- DSAPI / AgentAPI 等大模型接口调用。六类 Agent 属于项目管理实验过程中的模拟角色，不是预约网页运行依赖。
- 管理员后台、支付、通知和门禁系统。

## 5. 自动化测试

执行命令：

```bash
node --test tests/*.test.js
```

测试覆盖预约规则、时间边界、localStorage 登录/创建/冲突/归属/取消/释放/退出、损坏数据保护和存储不可用提示。实际测试结果以本次运行输出为准；浏览器端页面跳转、视觉布局和刷新持久化仍需在目标浏览器人工验收。
