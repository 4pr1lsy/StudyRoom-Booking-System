# 晨读 · 自习室预约系统 V0.3（网页核心版）

## 版本定位

本代码包只包含最终软件产品——自习室预约网页原型。项目管理实验中的六类 Agent（PM、Architect、Planner、Developer、QA、Change Control）用于模拟项目团队中的管理与开发职能，不属于学生预约网页的产品功能，因此本版本不包含 Agent 页面、Agent 脚本或 Agent API 接入。

## 运行方法

1. 解压 ZIP 压缩包。
2. 推荐使用 VS Code 的 Live Server 插件打开 `index.html`，再通过本地网页地址访问。
3. 也可以尝试直接用 Chrome / Edge 打开 `index.html`；若浏览器对 `file://` 下的 localStorage 隔离，页面之间可能无法共享数据。
4. 输入演示学号（3—20 位字母、数字、`_` 或 `-`）和昵称，进入预约系统。
5. 选择自习室、日期、起止整点时间和座位，确认预约；在「我的预约」查看、修改尚未开始的有效预约或取消预约。

## 技术栈和边界

- 原生 HTML、CSS、JavaScript 和浏览器 localStorage；无业务后端、无数据库、无前端框架。
- localStorage 仅在同一浏览器来源下保存数据，不具备跨设备同步、真实并发事务或生产级身份认证能力。
- 登录是课堂演示身份切换，不验证真实密码，不应录入真实敏感个人信息。
- 两间预设自习室，每间 12 个座位；可预约当天及未来 7 天，开放时间 08:00—22:00，按整点选择。
- 时间冲突采用半开区间 `[开始, 结束)`：例如 08:00—10:00 与 10:00—12:00 相邻，不视为冲突。
- 不允许预约已开始或过去的时段；允许修改尚未开始的有效预约日期和时间（房间、座位不可更换）；允许取消未结束的预约；取消记录保留，但不再占用座位。
- V0.2 保留 V0.1 的 localStorage 键名，原有演示数据可继续读取。
- V0.3 已实现 CR-001：有效预约修改、修改冲突校验、localStorage 安全更新和自定义取消确认弹窗。
- 本网页不调用 DSAPI、AgentAPI 或其他大模型接口。六类 Agent 的角色、交互和管理过程应在实验报告、提示词/记录及项目管理材料中单独体现；如需实际大模型辅助，属于项目管理实验过程工具，不是本网页产品的运行依赖。

## 自动化测试

安装 Node.js 后，在项目根目录运行：

```bash
node --test tests/*.test.js
```

运行网页本身不需要 Node.js。

## 演示数据重置

打开浏览器开发者工具，在 Application / Storage → Local Storage 中，删除 `studyroom.v01.bookings` 和 `studyroom.v01.currentUser` 两个键。此操作会清除当前浏览器中的演示预约和登录信息。
